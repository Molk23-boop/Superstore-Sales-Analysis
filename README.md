# Superstore-Sales-Analysis
Sales analysis of US Superstore data using MySQL for data cleaning &amp; querying and Power BI for visualization. Includes RFM customer segmentation and revenue trend analysis
## Project Overview
Analysis of US Superstore sales data (2014-2017) using MySQL and Power BI
to uncover revenue trends, product performance and customer behaviour.

## Dataset used
- <a href="https://www.kaggle.com/datasets/vivek468/superstore-dataset-final">Dataset</a>
## Business Questions
1. Which product categories are most/least profitable?
2. Are there seasonal patterns in sales?
3. Which customer segments drive the most revenue?
4. Which customers are at risk of churning?
5. Which states represent the biggest markets?
